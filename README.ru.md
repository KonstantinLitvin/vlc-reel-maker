# ReelMaker

[English](README.md) | [Русский](README.ru.md)

Расширения для VLC плеера предназначено для разбивки аудио и видео на фрагменты и навигации по ним. 
Размеченные видео сохраняются в формате `.scn`.
Наряду с разметкой доступен функционал по быстрому нарезанию размеченных видео/аудио отрывков на отдельные файлы.
Так же есть возможность экспортировать скрипт для кастомизации и последующей нарезки.
---

## Возможности

- **⏱️ Разметка фрагментов (Mark Start / Mark End)**: Захват текущих таймкодов воспроизведения с миллисекундной точностью прямо во время просмотра.
- **✏️ Редактирование сцен по месту**: Выберите любую сцену и нажмите **Редактировать**, чтобы изменить границы или название, после чего сохраните изменения кнопкой или клавишей **Enter**.
- **✂️ Нарезка через FFmpeg без перекодирования**:
  - **Нарезка выбранной сцены** 
  - **Экспорт скрипта нарезки**: Создание готового скрипта (`.sh` для Linux или `.bat` для Windows) для пакетной обработки.
- **🌐 Двуязычный интерфейс**: Полная локализация на русский (`ru`) и английский языки.
- **💻 Кроссплатформенность**: Поддержка Linux (включая работу в изоляции VLC Snap) и Windows (пакетные файлы `cmd.exe`, фоновые процессы `start /B`).

## Установка

Готовые скомпилированные бандлы расширения уже находятся в папке `dist/`.

### Windows

#### Вариант 1: Графический установщик (Рекомендуется)
Скачайте и запустите установочный мастер из [GitHub Releases](https://github.com/KonstantinLitvin/vlc-reel-maker/releases):
* `ReelMaker-Setup-v1.2.exe`

*(Поддерживает русский и английский интерфейс, автоматически устанавливает расширение в VLC и при желании настраивает FFmpeg).*

#### Вариант 2: Скрипт-установщик в один клик (Без интернета / Из репозитория)
Если вы клонировали репозиторий или скачали ZIP:
```cmd
scripts\install-windows.bat
```
*(Предлагает выбор языка: русский или английский, копирует `reel-maker.lua` в `%APPDATA%\vlc\lua\extensions\` и проверяет FFmpeg).*

#### Ручная установка
Скопируйте `dist/reel-maker.lua` (или `dist/reel-maker-ru.lua`) в:
```cmd
%APPDATA%\vlc\lua\extensions\reel-maker.lua
```

---

### Linux

Запустите скрипт установки:
```bash
./scripts/install.sh ru     # Русская сборка
./scripts/install.sh        # Английская сборка
```

Либо скопируйте `dist/reel-maker.lua` вручную:
- **Snap VLC**: `~/snap/vlc/current/.local/share/vlc/lua/extensions/`
- **Обычный (deb/rpm) VLC**: `~/.local/share/vlc/lua/extensions/`

### 3. Настройка FFmpeg (для нарезки прямо из VLC)

Расширение предоставляет два способа нарезки:
1. **Экспорт скрипта нарезки (`[ 📄 Скрипт нарезки ]`)**: Не требует установки FFmpeg внутри VLC. Создает скрипт (`.sh` или `.bat`) рядом с медиафайлом для запуска в терминале.
2. **Прямая нарезка из интерфейса (`[ ✂️ Нарезать ]`)**: Требует наличия FFmpeg, доступного плееру VLC.

#### Linux (VLC Snap)
Snap-пакет VLC изолирован от системных бинарников в `/usr/bin`. Установите автономный статический бинарник FFmpeg в общее окружение Snap одной командой:
```bash
./scripts/get-ffmpeg.sh
```

#### Windows
На Windows запустите скрипт автоматической установки:
```cmd
scripts\install-ffmpeg-windows.bat
```
Скрипт автоматически:
- Проверит наличие FFmpeg в `PATH`.
- При наличии `winget` установит пакет `Gyan.FFmpeg`.
- Или скачает автономный `ffmpeg.exe` напрямую в `%APPDATA%\vlc\bin\ffmpeg.exe`.

Либо установите вручную:
```cmd
winget install Gyan.FFmpeg
```
или поместите `ffmpeg.exe` в `%APPDATA%\vlc\bin\`.

## Использование

1. Откройте VLC Media Player и запустите воспроизведение медиафайла.
2. В верхнем меню откройте: **Вид** -> **ReelMaker v1.2** (или **View** -> **ReelMaker v1.2**).
3. **Рабочая папка и файл сцен**:
   - **Рабочая папка**: Определяется автоматически по расположению видео. Укажите другую папку, если хотите сохранять клипы и скрипты в отдельное место.
   - **Файл .scn**: Автоматически подставляется путь к файлу с расширением `.scn`. Если файл уже существует, сцены загрузятся автоматически.
4. **Разметка сцены**:
   - Нажмите `[ ⏱️ Метка [ ]` в начале нужного фрагмента.
   - Нажмите `[ ⏱️ Метка ] ]` в конце фрагмента.
   - Введите название сцены (или оставьте пустым — имя сгенерируется автоматически, например `Сцена 1`).
   - Нажмите `[ ➕ Добавить / Сохранить ]` или просто нажмите клавишу **Enter** в поле названия.
5. **Управление сценами**:
   - Выберите одну или несколько сцен в таблице:
     - `[ ▶ К началу ]`: Перемещает ползунок плеера на начало сцены.
     - `[ ⏹ К концу ]`: Перемещает воспроизведение на конец сцены.
     - `[ ✏️ Редактировать ]`: Загружает данные сцены в поля ввода. Для сохранения нажмите `[ ➕ Добавить / Сохранить ]` или **Enter**; для отмены повторно нажмите `[ ✏️ Редактировать ]`.
     - `[ ✂️ Нарезать ]`: Нарезает выбранные сцены через FFmpeg без перекодирования. Поддерживается множественный выбор (Ctrl/Shift) с отображением прогресса в реальном времени.
     - `[ 🗑️ Удалить ]`: Удаляет выбранные сцены, автоматически перенумеровывает оставшиеся и сохраняет `.scn` файл (при удалении нескольких сцен запрашивается подтверждение).
6. **Пакетный экспорт**:
   - Нажмите `[ 📄 Скрипт нарезки ]`, чтобы сгенерировать готовый исполняемый файл `movie_cut_scenes.sh` (или `.bat`) в рабочей папке.

## Разработка и сборка из исходников

Исходный модульный код расположен в папке `src/`. Готовые собранные файлы для релиза (`dist/reel-maker.lua`, `dist/reel-maker-en.lua`, `dist/reel-maker-ru.lua`) можно пересобрать самостоятельно:

### Linux / macOS
```bash
./scripts/build.sh          # Собрать все бандлы (по умолчанию английский)
./scripts/build.sh ru       # Собрать только русскую версию
```

### Windows (Командная строка CMD / PowerShell)
```cmd
scripts\build.bat           # Собрать все бандлы (по умолчанию английский)
scripts\build.bat ru        # Собрать только русскую версию
```
*(или напрямую через Lua/LuaJIT: `luajit scripts/build.lua`)*

### Сборка установщика Windows (.exe)
Требуется [Inno Setup 6](https://jrsoftware.org/isdl.php):
```cmd
iscc scripts\reel-maker.iss
```
